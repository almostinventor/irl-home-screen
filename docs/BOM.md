# Parts list

Electronics used on the reference build:

| Qty | Part |
| --- | --- |
| 1 | LOLIN S2 Mini (ESP32-S2) |
| 1 | TMC2209 stepper driver |
| 1 | Stepper motor for the rail |
| 2 | Servos for the pushers (MG90S) |
| 2 | Microswitches (rail endstop, lever) |
| 1 | 1k resistor |
| 1 | Motor power supply |
| 1 | 5 V supply for the board and servos |

Plus a rail and carriage, the printed parts in [`hardware/stl/`](../hardware/stl/), a
projector, and a laptop to run the app.
