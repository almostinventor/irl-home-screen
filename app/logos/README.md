# Logos

Put your own game logo images here. None are included in this repository.

- Name them by the `asset` number of the game in `SLOTS` (in `projector.html`), zero-padded to
  two digits: `asset: 7` uses `07.png`.
- PNG with a transparent background looks best on a projector. Anything around 600 px wide is
  plenty.
- A game with no logo file simply shows its title as text instead.

Image files in this folder are ignored by git (see `.gitignore`), so your own artwork stays on
your machine.
